# AuraDrop COTURN Relay Server Infrastructure

This directory contains the production STUN/TURN server configuration for AuraDrop.

## Why COTURN is Needed
WebRTC P2P direct connections succeed in ~85-90% of networks (same LAN, UPnP, full-cone NAT). However, when one or both devices are behind symmetric NATs, carrier-grade NATs (CGNAT, common on mobile 5G/4G), or restrictive corporate firewalls, direct UDP hole punching fails.

AuraDrop uses **COTURN** as a high-performance media/data relay fallback using RFC 5766 TURN with dynamic HMAC-SHA1 ephemerally signed credentials generated by the AuraDrop Signaling Server.

## Architecture & Credential Generation
1. Web client or Android client requests ephemeral TURN credentials from `/turn/credentials?deviceId=...`.
2. The signaling server calculates:
   - `username`: `<timestamp + 86400>:<deviceId>`
   - `password`: `Base64(HMAC-SHA1(username, TURN_SECRET))`
3. Client passes these credentials to `RTCPeerConnection`:
   ```ts
   iceServers: [
     { urls: 'stun:stun.l.google.com:19302' },
     {
       urls: [
         'turn:turn.auradrop.network:3478?transport=udp',
         'turn:turn.auradrop.network:3478?transport=tcp'
       ],
       username: creds.username,
       credential: creds.password
     }
   ]
   ```
4. COTURN verifies the HMAC using the shared `static-auth-secret` and grants relay bandwidth without storing passwords.

## Deployment Instructions

### 1. Requirements
- A VPS with a public IPv4 address (e.g. AWS EC2, DigitalOcean Droplet, Hetzner Cloud, GCP Compute Engine).
- Ports open on firewall/security group:
  - `3478/tcp` & `3478/udp` (STUN/TURN)
  - `5349/tcp` & `5349/udp` (TURNS with TLS)
  - `49152-65535/udp` (Relay UDP port pool)

### 2. Deploy with Docker Compose
```bash
cd infra/turn
docker compose up -d
```

### 3. Native Ubuntu/Debian Deployment
```bash
sudo apt-get update && sudo apt-get install -y coturn
sudo cp turnserver.conf /etc/turnserver.conf
sudo systemctl restart coturn
sudo systemctl enable coturn
```

### 4. Verify Server
```bash
turnutils_uclient -u testuser -w secret -s 127.0.0.1 -p 3478
```
